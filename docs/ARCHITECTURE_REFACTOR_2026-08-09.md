- 仅允许 IBKR Paper `DU` 账户和端口 `4002`。
- 只允许整股、限价单；Live、做空、碎股、期权和保证金借款仍关闭。

- 大模型不进入实时信号、风控、订单或恢复链路。

## 多级菜单流程

默认桌面使用左侧一级模块菜单：今日运行、针对性验证、研究工坊、系统与审计；每次只显示一个模块。今日运行、研究工坊和系统审计通过二级页签拆分功能，自动量化详情与针对性验证保留三级页签。页面实例始终保留，菜单切换不重建控件或改变业务状态；滚动仅属于当前功能页。小于 1240px 时一级菜单自动收窄并保留完整的可访问名称和提示。旧界面通过 `US_QUANT_LEGACY_UI=1` 保留稳定回退入口。

## Paper 状态机

```text
IDLE → PREPARING → READY → CONNECTING → RUNNING/PAUSED
                                      ↓
                                   STOPPING
                                      ↓
                                  FINALIZED

任一不确定状态 → HALTED → RECONCILING → RECONCILING_READY
                                             ↓ 人工二次确认
                                           RUNNING
```

人工对账不是简单重连。系统会刷新账户、持仓、开放订单、完成订单、成交和完整本地对账汇总，生成与连接代次、账户指纹、会话、引擎精确状态和券商摘要绑定的一次性证据。确认时再次刷新并比对；过期、重复、断线或任一差异都回到 `HALTED`。

停止后的租约释放也采用两段式证明：先在连接中证明本地/券商/日志均为零，再断开并等待回调线程结束，最后排空迟到事件并复核。迟到成交会阻止最终化。BUY 超时可以精确撤销本会话订单；SELL 退出单超过 90 秒只触发人工干预停机，不会自动撤掉保护性退出。

## 研究数据可信度

当前官方名录约 11,144 个上市证券，本地日线覆盖约 603 个代码。历史横截面仍使用当前上市成员，因此存在幸存者偏差。旧文件还缺少正式价格口径元数据，主要属于复权研究代理。

数据使用分为：

- `EXPLORATORY`：允许读取旧/复权研究数据，结果只能是探索性且不可部署。
- `EXECUTION_CANDIDATE_PIT_RAW`：仅允许 `raw_trade_ohlc`，并要求明确的历史时点成员证据；缺任一项立即拒绝。

新增点时成员、公司行动和退市结算数据契约；在可靠数据源尚未补齐前，不会把当前成员快照冒充历史成员。每次横截面研究都会写入运行清单，包括官方成员快照哈希、实际入选代码、每个历史文件的哈希/来源/价格口径/覆盖日期和 PIT 标记。

日线研究默认只评估一个预先声明的固定假设：126 日回看、21 日再平衡、Top 3。原 8 组网格仍可显式选择为探索性搜索，但不会再作为默认流程。所有结果继续标记 `research_exploratory`、`deployable=false`，不会自动晋级。

日内研究新增可选 SPY/QQQ 市场状态版本：只有参考行情新鲜、连续且最近一分钟不为负时才允许新 BUY；止损、止盈、跟踪止损、时间退出和用户停止 SELL 不受该门影响。
