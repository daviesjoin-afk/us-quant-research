# 美股量化研究台使用说明

## 启动

双击 `USQuantResearch.exe`。本程序是 Windows 64 位本地客户端，不需要单独安装 Python。

需要从 IBKR 下载历史数据或只读账户信息时，请先登录 IB Gateway 模拟账户，并保持：

- Socket 端口 `4002`
- API 只读开启
- 只允许本机连接

仅观察时建议保持 Gateway 的“只读 API”开启。要运行 IBKR Paper 自动量化，
需要关闭 Gateway 的“只读 API”，再通过客户端设置开关和当次会话确认双重武装；
关闭 Gateway 只读并不会让客户端自动下单。

Gateway 未连接时，已下载的数据、标的池、扫描、策略管理和内部仿真审计仍可离线查看。

## 首期边界

- IBKR Live 永久关闭。自动下单只允许 IBKR Paper 单一 `DU` 账户的整股
  `DAY LMT`；市价单、做空、保证金借款、全撤和期权行权均无入口。
- 只研究股票和明确白名单 ETF。
- 不做碎股，所有资金容量均按整股向下取整。
- 只排除中概股；加拿大、欧洲、日本、韩国、台湾地区等其他市场公司可以研究。
  排除证据来自 Nasdaq Country=China/Hong Kong/Macau、SEC 主营地/注册地
  和本地可审计拒绝清单；这不是政府或法律意义的国别认证。
- 板块龙头和优质二线可进入候选；广域后排只用于研究比较。
- 杠杆或替代执行品只作为通用执行策略处理，不作为独立 Alpha 策略或重点标的；统一执行风险倍数、整股和最长持有期约束。

## 外部实时行情

客户端支持两个免费外部源：

- Alpaca：IEX 单交易所实时 bid/ask，不是 SIP/NBBO，最多 30 个代码；
- Finnhub：实时成交打印；免费流不是 bid/ask，程序显示 ±5bps 的保守影子
  执行带并逐行标注“非市场盘口/NBBO”；
- IBKR 5×24：盘前、常规、盘后使用 IBKR 行情；隔夜时改为直接请求
  `OVERNIGHT` 路由。实际报价权限和每个标的的隔夜资格仍以 IBKR 回调为准；
- Finnhub Key、Alpaca API Key/Secret 均使用 Windows DPAPI 按当前用户分别加密保存，不写入普通设置、源码、日志或导出，并可在客户端清除；
- 缺 bid/ask、超时、断线和非实时数据都显示 `STALE`，不进入日内信号。

Finnhub 只需要 API Key；Alpaca 需要 Key 与 Secret。请在“系统·设置”页填写并
点击“加密保存输入的凭据”。保存后输入框会清空，只显示已保存状态。不要把密钥
发到聊天、截图或日志中。点击“启动只读流行情”，等至少一个代码显示 `READY`。

## 外观、设置与行情表性能

- “系统·设置”可在深色、浅色主题之间切换并保存默认行情源；API 凭据通过数据源下拉框分别管理；
- 0.18 版将行情、自动量化、针对性日内 T、回测与设置页改为分组网格；
  在 1120×720 至 1920×1080 的常见窗口尺寸下，长策略名、资金输入、
  复选框和操作按钮不会相互遮挡；输入完整内容可通过悬停提示查看；
- 行情处于连接中、延迟、报错或重连时仍可选择其他数据源；“切换 / 重连行情”会安全停止旧源后启动新源；
- 行情角色可由 Finnhub、Alpaca 或 IBKR Market Data 承担；券商角色当前为 IBKR Gateway Paper。即使都选择 IBKR，两种角色和状态仍独立显示；
- "IBKR 5×24（盘前 / 盘后 / 隔夜）"会在美东 20:00 自动切换至
  `OVERNIGHT` 行情路由，并在 04:00 切回 `SMART`；周末和美东
  03:50–04:00 维护间隙不会把 stale 行情当作可交易信号；
- IBKR 连接可保存 Host、Client ID 和超时，安全模型仍强制本机及 Paper 端口 4002；
- “允许 IBKR Paper 模拟下单能力”默认关闭。开启只保存能力标志，不会立即
  提交订单；真正运行还需在“自动量化”完成两步并在启动弹窗确认。适配器强制
  单一 DU、端口 4002、整股、单笔上限、会话候选集和券商回报对账；
- “启用 IBKR Paper 5×24 扩展时段”只影响 Paper：盘前/盘后使用
  `SMART + OutsideRth` 整股限价单，隔夜使用 `OVERNIGHT` 整股限价单；
  周末、全日休市、无新鲜实时行情和美东 03:50–04:00 维护窗口均禁止提交订单；
- 行情表采用增量数据模型，每 500ms 合并最新快照；拖动横向或纵向滚动条时暂停表格绘制，松手后仅补最新一帧；
- 所有数据表改用交互式固定列宽和像素级滚动，分栏拖动期间关闭实时重绘，
  避免数据更新时重复测量全部单元格造成卡顿；
- 系统不保存固定股票池或交易白名单；旧版本遗留的 `watchlist` 设置会在启动时自动移除；API 凭据始终与普通设置分离。

广域研究池覆盖全部合格的非中概股票和 ETF。行情页代码框只是一次实时连接的
订阅窗口；程序可从最新广域扫描临时选取不超过 30 个代码，以控制单连接的刷新
负载，但这不会缩小研究范围，也不是固定股票池或交易白名单。候选选择仍以
龙头/优质二线、板块分散和整股可执行优先，并保留少量市场参照 ETF。

行情页会同时显示“官方美股/ETF、排除中概后的研究池、已有日 K、最近实际扫描”
四层数量。市场扫描页默认显示全部已评分代码，并单独列出缺少或不足 200 根日 K
的数量；筛选器只改变表格显示。若扫描覆盖不足，在“市场研究 → 数据任务”点击
“将全部非中概研究池加入队列”，程序会把全部合格代码排入 SQLite 队列，再按
所选批量逐步下载；不再只安排前 500 个。实时订阅仍最多 30 个，历史研究队列
和广域扫描不受这个上限影响。

## 策略与回测工作区

一级导航已重组为“监控台、策略与回测、市场研究、运维与安全、系统设置”。
“策略与回测”包含：

- 策略目录与版本：不可变版本、参数哈希、代码哈希、状态和晋级阻断；
- 回测工作区：买入持有基准、双均线趋势、唐奇安突破、RSI 短期均值回归；
- 横截面研究：广域龙头/优质二线的组合走样本外研究。

单标的回测使用收盘生成信号、下一交易日开盘成交，执行整股、最低佣金和滑点。
每次运行生成独立 Run ID，绑定策略版本 ID、参数哈希和数据哈希，并将权益曲线、
指标及交易明细写入用户研究目录。复权日 K 回测始终标注为研究代理，不得作为
历史可成交表现或盈利保证。

## 自动量化与 IBKR Paper

“监控台 → 自动量化”是主执行页，而不是针对某一只股票：

- 从最新广域扫描动态生成候选，不保存固定观察池；候选必须通过非中概、
  股票/ETF、龙头层级、整股容量和实时行情门；
- 主视图只显示 Paper 净值、已实现/未实现盈亏、当前持仓和运行状态；
  候选信号及 Paper 订单放在二级页；
- 先点击“第 1 步：全市场扫描并准备行情”。系统会扫描全部非中概研究池，
  将历史数据缺口加入数据任务队列，并按 Paper 账户资金选出最多 30 个
  实时轮动候选；当前 fresh 至少 3 个后，再点击“第 2 步”并确认；
- 启动区集中显示 Paper 能力、策略、动态候选、实时行情和账户资金五项检查；
- 会话资金上限只限制本次策略；0 表示使用 Paper 净值与现金中的较小值，
  不会用历史研究资金替代账户真值，也不会借款；
- 自动轮动 `1.1.0-research` 增加连续动量和单分钟异常跳变过滤，仍需
  Paper 样本外验证，不代表盈利能力；
- 首期要求单一 DU 模拟账户且启动时空仓，最多同时持有一个标的；
- 默认只提交 `SMART/USD` 整股 `DAY LMT`；开启 5×24 Paper 后，盘前/盘后
  仅以 `OutsideRth` 限价单路由，隔夜仅以 `OVERNIGHT` 限价单路由；不提交
  市价单、碎股、做空、期权或 Live 订单；
- “暂停新开仓（保留持仓）”会撤销未成交买单，但已有持仓的止损、止盈和
  时段退出继续运行；“停止会话并请求平仓”才会主动退出持仓并等待券商对账；
- 净值、持仓与盈亏优先使用 IBKR Paper 回报，本地估算只作为辅助。
- 连接时读取券商开放订单、当日逐笔成交和已完成订单。`Filled`、拒单或撤单
  只有在订单状态数量与逐笔成交数量一致后才算已核对；
- 断线、拒单、非整股回报、持仓不一致或提交结果不确定都会停止新订单，
  不会按分钟自动重试。“Paper订单”页显示简化后的执行健康和具体差异；
- 未成交 BUY 超时或用户停止时仅撤销本会话对应订单，不提供全局撤单；
- “断线后重新连接对账”只恢复账户、持仓、订单和成交快照，不会自动恢复
  策略交易。存在持仓或未对账订单时不会把会话标记为安全结束；
- 脱敏导出同时包含 `paper_orders.csv` 和逐笔 `paper_executions.csv`。

## 内部策略仿真

“针对性日内 T”中的内部策略仿真指 `internal_shadow`，不是 IBKR Paper 订单：

- 在该页输入你要研究的股票或 ETF；程序启动时
  默认留空，实时订阅、分钟回放、多日评估和影子做 T 共用这一入口，不含
  任何代码专用替代规则；
- 启动前必须先读取 IBKR Paper 账户，以券商返回的 `NetLiquidation`
  作为影子初始现金；快照超过 5 分钟或没有账户资金真值时拒绝启动；
- 必须绑定指定标的日内 T 的不可变策略版本；research 版本明确标为探索性；
- $1,500 仅是默认历史研究情景，可在“策略研究”页修改，不代表账户余额；
- 只接受已通过中概排除证据门及龙头/优质二线门的代码；
- 只做整股；单仓风险预算 10%，杠杆或替代执行品按风险倍数折算；
- 模拟买入价为 ask 加 2bps，卖出价为 bid 减 2bps；
- 每张订单扣 $0.35，盈亏按双边成本计算；
- 至少 10 个独立分钟样本预热，纽约时间 10:00 前不入场；
- “回放已录分钟数据”只使用最近一个纽约常规交易日，不会把多天分钟串成一次回放；
- “多日稳健性评估”只计入覆盖纽约 10:00–15:45、至少 300 条可用分钟并满足连续预热的交易日，再独立运行基准和四组 ±20% 参数扰动；收益方向一致不等于盈利，少于 20 个真实会话仅供探索；
- 达到 20 个完整会话后自动生成时间隔离验证：10 个训练会话选参、5 个验证会话门控、5 个未参与选择的测试会话报告，并随新增会话滚动扩展；
- 时间隔离基准与策略使用相同 10% 风险预算、整股、滑点和佣金；“测试超额”不参与参数选择，任何结果都不会自动晋级；
- “过拟合诊断”对固定候选集运行 10 分区 CSCV/PBO 与 DSR；少于 20 个同步会话或收益方差不足时显示“不可估计”，不生成替代分数；
- PBO、DSR 和样本外退化只用于识别研究选择偏差，不能作为自动晋级或自动下单授权；
- “独立评审”逐项展示证据身份、真实流来源、25 个完整会话、两折验证、PBO/DSR、样本外超额、相关性折算样本量、HAC 置信度、整股成本和成交硬门；
- “数据质量”按 346 个预期分钟展示完整率、连续缺口、stale、异常报价、
  源端年龄和最优档数量覆盖；“执行压力”重跑 5bps、10bps+双倍佣金并估算
  整股成交相对 Level-I 最优档数量的参与率；
- `synthetic_preview` 与 `imported_research` 只能用于软件或研究验证，不能通过真实流来源门；全部硬门通过也仅允许进入人工独立评审；
- 单日最多 4 笔完成交易、亏损达到影子初始资金 1% 停机、
  15:45 前强制影子平仓；
- “执行前检查”二级页将身份、非中概、策略、行情、资金、整股容量和分钟
  证据整理为通过/阻断结论；
- 该内部仿真没有券商订单方法，因此不会误发 IBKR 订单。

使用顺序：

1. “账户与持仓”中读取 IBKR Paper 账户资金真值；
2. “实时行情”中等待 `READY`；
3. “策略版本”确认晋级门和 Paper Shadow 状态；当前默认版本因复权价
   不可执行而保持硬阻断；
4. 仅在门控通过后，才可在“针对性日内 T”启动内部策略仿真；
5. 查看当前持仓、成交原因、来源覆盖、已实现/未实现盈亏；
6. 结束时点击“停止并影子平仓”；
7. 在“运行中心”导出脱敏账户、行情、策略、事件和影子成交。

## 推荐操作顺序

1. 在“总览”检查 Gateway、账户、行情和安全门。
2. 在“账户与持仓”读取 IBKR Paper 账户、持仓和盈亏。
3. 在“标的池”刷新官方目录和 SEC 核验资料。
4. 在“数据队列”生成队列，每批下载 10–25 个标的。
5. 下载完成后进入“市场扫描”运行扫描。
6. 在“实时行情”连接 Finnhub、Alpaca IEX 或可用的 IBKR 实时数据。
7. 若仅研究单票，进入“针对性日内 T”；若验证自动执行，进入“自动量化”，
   明确确认后再武装 IBKR Paper。

历史数据下载可中断续跑。失败任务可在“数据队列”中重新放回待处理状态。

如果 IBKR 因“其他 IP 的交易会话”拒绝历史数据，可以使用“备用免费日 K（仅研究）”补齐历史样本。备用数据会单独记录来源，只能用于离线策略筛选，不能代替 IBKR 实时行情、成交价或实盘决策数据。

## 重要说明

评分是研究排序，不是收益承诺或自动买入指令。IEX 影子成交也不是实际可成交证明。
策略必须继续通过走样本外、交易成本、市场状态和足够多交易日的 Paper 验证。
现有 Paper 订单适配器只用于模拟成交与执行链路验收，不构成收益保证。
