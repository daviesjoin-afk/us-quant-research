# 需求清单

## 用户约束

- 本金较小，高价股要考虑集中度和整股可买性。
- 指定标的由用户在统一入口输入，不使用任何股票或 ETF 的硬编码替代映射。
- 希望交易频率在扣除券商佣金后仍有意义。
- 最大可接受回撤很高，但程序首期采用更严格的默认保护，不把容忍度当作目标。
- 最终需要完整可视化 Windows 客户端和可双击运行的打包文件。

## 当前交付范围

- 大范围官方代码目录与可审计排除原因
- 中概严格关闭
- 龙头、优质二线、广域研究后排三层
- 整股扫描与资金容量
- 历史队列、断点续跑、数据质量
- 市场扫描与组合走样本外
- 桌面端与 Windows 压缩包

## 暂不开放

- 自动 Paper 下单
- Live 连接
- 期权和杠杆实盘
- 日内做 T
- 大模型实时决策

这些能力必须在实时权限、双源对账、影子信号、Paper 成交和故障恢复验收后分阶段开放。
