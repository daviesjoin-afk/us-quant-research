# 项目状态：广域扫描与桌面客户端

## 已完成

- Nasdaq Trader 官方目录：10,878 个当前股票/ETF 代码。
- SEC EDGAR 注册地、主营地址、申报类型和 SIC 行业增量核验。
- 中概严格关闭：广域股票必须同时满足美国注册、美国主营地址和国内 `10-K`；证据不足不放行。ETF 只用人工复核白名单。
- 193 个首批已核验研究标的；其中 86 个为龙头/优质二线交易资格层，后排只作横向研究。
- 187 个标的已取得约 5 年日 K，186 个通过 200 日最低样本门。
- 日 K 扫描：趋势、动量、波动、回撤、流动性、RSI、ATR、整股容量、板块层级和替代执行。
- 已取消单一代码的强制替代映射；指定标的由用户输入，扫描与执行均不使用碎股。
- 8 组组合参数、6 个完整 126 日走样本外折、佣金和滑点模型、SPY 整股基准。
- Qt Windows 桌面端：总览、标的池、市场扫描、策略研究、数据队列和风控说明。
- IBKR 历史下载队列支持断点恢复、失败重试和质量门。

## 当前研究结论

组合研究的样本外区间为 2023-07-13 至 2026-07-17。走样本外选择从第二折开始稳定选中 `126 日动量 + 月度调仓 + 3 个板块分散持仓`。

当前结果较强，但不能作为 Paper 自动下单批准，主要原因：

- 使用当前上市与当前龙头池，存在幸存者偏差。
- IBKR 因其他 IP 交易会话拒绝新一轮历史请求；多数扩展样本暂用备用公开调整日 K。
- 最后一折贡献较大，且策略最差单日约 -13.4%、最大回撤约 25.2%。
- 日 K 无法验证日内做 T、点差、部分成交和止损成交概率。
- 尚未完成逐日成分历史、退市样本、公司行动双源对账和 Paper 影子运行。

因此客户端仍然没有下单按钮，IBKR API 保持只读，所有结果均标记为研究。

## 下一轮验收

1. 退出占用同一 IBKR 用户的其他 IP 交易会话，重试 IBKR 历史队列。
2. 对至少 50 个核心标的做 IBKR 与备用源的逐日价格/成交量差异检查。
3. 加入历史成分与退市样本，降低幸存者偏差。
4. 做按年份、板块剔除、成本倍增和参数扰动稳定性。
5. 实时行情权限生效后，只做影子信号；再讨论是否开放 Paper 下单。
